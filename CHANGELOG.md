# Revision history for SFBDT

## 0.1.0.0 -- 2026-03-26

* Named LTIBDT (Local Type Inference BiDirectional Typing). Refer to Benjamin Pierce's and David Turner's paper Local Type Inference, 2000. Particularly, the type system without Bounded Quantification.

## 0.2.0.0 -- 2026-03-30

* Still named LTIBDT (Local Type Inference BiDirectional Typing). Still refer to Benjamin Pierce's and David Turner's paper Local Type Inference, 2000. Particularly, the type system without Bounded Quantification. Now, LTIBDT has typing, examples and is in general complete. Only minor bugfixes should follow, if there are any which may be noticeable.
